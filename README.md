# 公考日历

集中记录国考与各省公务员考试的报名、缴费、准考证打印、公共科目笔试日期和官方链接。参考 CCF Deadlines 的集中时间看板思路，独立实现。

**网站：https://lifeixiao.github.io/civil-service-deadlines/**

- 32 个考试地区：国考 + 中国大陆 31 个省级地区。
- 按地区、招录年度、办理阶段筛选；按最近时间节点排序。
- 北京时间倒计时、浏览器本地关注、ICS 日历导出。
- 每条时间保留来源与证据短句，人工核验与自动提取分开标示。
- GitHub Actions 每天北京时间 **07:23** 检查官网并重新发布。打开网页会请求最新发布的快照；可见页面每 5 分钟再读一次。
- 无账号登录、无收费服务、无模型 API、无本地常驻程序。

## 日期覆盖和可信度

**配置 32 个来源不等于已完整收录 32 个地区的时间表。** 页面显示实际收录数量；“待收录”不表示官方尚未发布。首版已核验国考、北京、上海、江苏、浙江、广东、山东省级机关、四川省级机关等记录，覆盖情况随公开数据更新。

数据优先来自配置中的官方门户、考试机构和政府机构转载；少量经交叉核验的媒体转载会在记录说明中标明原始来源。浙江省级公告采用金华新闻网注明来源为浙江组工的转载，并与湖州组织工作网的当年公告交叉核验。遇到验证码、证书异常、拒绝访问、动态页面或超时，会记录检查状态并保留旧数据；不会绕过访问控制。部分官网需要继续补充适配或人工核验，不能保证全天实时或自动完整覆盖所有省份。

自动提取只处理带明确年度、可解释的日期片段。未标明时刻则保留日期精度；未给出结束时间则不补造。调剂、遴选、面试、专业测试等不能混入普通招考时间表。延期、更正、分批次和市级专属公告会进入待核验记录；与已有日期冲突时不会静默覆盖。公共科目笔试之外的专业科目请读原文。

GitHub 的定时任务可能延迟。数据来源弹窗提供每个地区的本次检查状态、最后找到公告的时间和检查记录。日历导出为一次性文件，后续日期变更需要重新导入。

## 更新与发布

整个流程由 [calendar.yml](.github/workflows/calendar.yml) 完成：

1. 校验解析规则、日历和现有数据。
2. 定时任务或手动运行时，检查官网并更新 `data/`。
3. 保存新增公告、时间和失败诊断到仓库。
4. 打包静态页面并部署 GitHub Pages。

首次在仓库 **Settings → Pages → Build and deployment → Source** 中选择 **GitHub Actions**。本项目已经启用；不需要配置个人访问令牌或额外密钥。

需要立即检查时，在 **Actions → Update calendar and deploy Pages → Run workflow** 中运行，保留 `update_sources` 为 true。修改网页后推送 main 也会自动部署，但不会重复扫描全部官网。

## 维护数据

| 文件 | 用途 |
| --- | --- |
| `data/sources.json` | 地区、官方入口、公告栏目、可信域名、已知公告链接 |
| `data/overrides.json` | 人工核验的日期，优先于自动提取；新增年度应添加新记录 |
| `data/exams.json` | 持久化时间记录，保留网络失败前的数据 |
| `data/notices.json` | 自动发现的公告、变化及待核验记录 |
| `data/status.json` | 最近尝试和每个来源的读取情况 |

补充公告时可[提交数据问题](https://github.com/lifeiXiao/civil-service-deadlines/issues/new?template=data.yml)，也可直接修改来源和人工核验数据提交 PR。请附官方原文，不按历史年份推算新日期，不把市级或特定机关专属安排泛化为全省安排。更正已确认的时间请修改人工核验记录；自动提取产生冲突时保留旧值等待处理。

同一个地区同一年度的多轮招录目前不会自动合并；带“上半年”“下半年”“第几批”等标题需要人工区分。本版主要覆盖常规统一招录。

## 本地开发（可选）

只需 Python 3.12+ 和 Node.js 24+，不需要安装第三方包。日常更新运行在 GitHub，不使用维护者电脑资源。

```sh
python -m unittest discover -s tests -v
node --test tests/*.test.js
python -m scripts.build
python -m scripts.serve
```

预览：`http://127.0.0.1:8765/`。手动抓取：

```sh
python -m scripts.update
python -m scripts.update --only jiangsu,beijing --timeout 12
```

静态文件全部使用相对地址，兼容 GitHub 项目路径及自定义域名。若使用自定义域名，需要拥有该域名并在 Pages 配置 DNS；默认 GitHub 地址免费可用。
